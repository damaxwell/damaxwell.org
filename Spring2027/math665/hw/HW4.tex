\problem Let $X$ be a set endowed with the discrete metric $d_{\mathrm{disc}}$.
Show that a sequence $(x_n)$ in $X$ converges to a limit $x$ if and only
if there is $N\in \Nats$ such that if $n\ge N$ then $x_n = x$.  
That is: the convergent sequences are exactly the eventually constant sequences.

\problem Let $(X,d_X)$ and $(Y,d_Y)$ be metric spaces.  Show that
a sequence $(x_n,y_n)$ in $X\times Y$ converges to a limit $(x,y)$
if and only if $x_n\to x$ and $y_n\to Y$. Using the notation 
at the bottom of page 43, prove the result 
is true when $d_{X\times Y}$ is either of $d_1$ or $d_2$. It's easy to 
see that it's also true for $d_\infty$ as well, but you need not show this.

\problem Suppose $(x_n)$ is a sequence in a metric space $(X,d)$.
Show that if $x\in X$ and if there is an $\epsilon>0$ such
that $d(x,x_n)\ge \epsilon$ for all $n$ then $x_n\not\to x$.

\problem Modify the proof from class for real valued functions to show 
the following. 

Suppose $(X,d_X)$ and $(Y, d_Y)$ are metric spaces, that 
$f:X\to Y$ and that $a\in X$. Then $f$ is continuous at $a$ if and 
only if for every sequence $(x_n)$ in $X$ converging to $x$, $f(x_n)\to f(a)$
in $Y$.
